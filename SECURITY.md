# Security Policy

## Reporting a Vulnerability
Please report security issues by email:

- felix.gutierrez@proxoffensive.com

Include:
- a brief description of the issue
- steps to reproduce (sanitized)
- impact assessment
- any suggested remediation

Do not open public issues for sensitive disclosures.

## Scope
This is a lab repository. Findings should be limited to the contents of this repo (documentation, scripts, tooling). There is no bug bounty program implied.

## Coordinated Disclosure
Please allow time for review and remediation before public disclosure.
