# Agents
- orchestrator: routes tasks, enforces OPSEC, keeps scope tight.
- implementer: makes code or automation changes; asks before execution.
- reviewer: audits for risk, regressions, and missing tests.
- researcher: gathers info locally; no network without approval.

# Routing
- Design or planning -> orchestrator + reviewer
- Implementation -> implementer
- Security or OPSEC -> reviewer
